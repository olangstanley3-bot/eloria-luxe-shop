# Eloria Luxe Design

Use this as your prompt in Lovable. It's much more detailed and geared toward producing a premium, modern e-commerce experience.

Prompt:

Design and build a premium, luxury-inspired e-commerce website for Eloria Store, a modern fashion and home décor brand specializing in curtains, handbags, and ladies' shoes. The website should feel elegant, sophisticated, and trustworthy, with a clean minimalist aesthetic that rivals high-end online stores.

Design Style

Modern luxury with a feminine yet professional look.

Premium typography (Poppins, Manrope, or Inter).

Soft neutral color palette featuring white, beige, champagne gold, charcoal, and subtle blush accents.

Rounded cards, soft shadows, glassmorphism where appropriate, smooth animations, and generous whitespace.

Fully responsive on desktop, tablet, and mobile.

Fast loading and optimized performance.
